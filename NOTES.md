# Notes

## Teaching preferences

- **Sources should come from architectural masters** where possible — primary texts, built works, and lectures from recognised architects rather than web guides or listicles. The user finds lessons significantly better when grounded in authoritative voices.

## Course context — the default lens

The learner is building a home in **Pokuase, Ghana** (hot, humid tropics, ~6°N). That context is the course's default, applied across every lesson:

- **Climate is the anchor, not temperate.** Orientation, ventilation, shading, ceiling height and indoor–outdoor living all assume hot-humid tropics — the sun is mostly to be *kept out* and the breeze *let through*. Never fall back on "capture the sun" / cold-climate logic.
- **Universal principles, tropical defaults.** The master principles hold everywhere; make the examples, defaults and the "why" tropical. Where climate-relevant, draw on tropical/vernacular masters (Hassan Fathy, Geoffrey Bawa) alongside the canon.
- **Metric (SI) everywhere.** No imperial units.
- **De-Westernise the program, don't re-stereotype it.** Avoid US/EU-specific room defaults (mudroom, basement, attached garage, formal dining) as the assumed vocabulary; use climate-neutral or tropical-inclusive examples (veranda, courtyard, outdoor kitchen) as *options*. Don't assume a generic "African home" program either — the learner's *specific* program belongs in the capstone, not baked into lessons.
- **Keep it a light anchor.** Weave the context in as backdrop; don't turn lessons into analysis of the learner's own plan (that's the capstone).

## Lesson structure

- **Layer, don't split.** Prefer one longer lesson per topic that progresses from basics to depth, over separate "basic" and "deeper" lessons. Length is fine; *undifferentiated density* is the enemy, not length.
- **The lesson spine:**
  1. **Orientation** — why this matters to the mission.
  2. **Tier 1 · Core** — the basics → one tangible win → checkpoint quiz → an explicit "you can stop here and already be ahead" marker.
  3. **Tier 2 · Deeper** — master-grounded depth, with its own checkpoint.
  4. *(optional)* **Tier 3 · Apply** — run it against the user's real plan.
  5. Primary source (a master), glossary links, ask-the-teacher, next lesson.
- Tiers are visually signposted as "chapters" so working memory always knows where it is, and each depth tier is gated behind a checkpoint quiz.

## Course arc

- The "put your own floor plan through everything you've learned" session is the **capstone**, saved for the **end of the series** — not interleaved between lessons. The user wants to learn the full toolkit first, then apply it to their real plan in one pass.
